# EKS GitOps Platform Apps

FastAPI application and Kubernetes manifests for deployment to Amazon EKS through GitOps.

## Overview

This repository contains the sample Python web application, container build configuration, Kubernetes manifests, and GitOps-managed deployment resources used by Argo CD to deploy the workload into the EKS platform.

The repository works together with the infrastructure repository, which provisions the AWS platform components such as VPC, EKS, ECR, IAM, and the AWS Load Balancer Controller.

The application is delivered to the cluster declaratively through Argo CD, which continuously reconciles Kubernetes manifests from Git into the running environment.

## Example Ingress

The application is exposed through a Kubernetes Ingress that uses AWS Load Balancer Controller annotations to create an internet-facing ALB. The controller supports ALB-specific ingress annotations such as scheme and target type.

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: flaskapp
  namespace: fastapi-app
  annotations:
    kubernetes.io/ingress.class: alb
    alb.ingress.kubernetes.io/scheme: internet-facing
    alb.ingress.kubernetes.io/target-type: ip
    alb.ingress.kubernetes.io/listen-ports: '[{"HTTP":80}]'
    alb.ingress.kubernetes.io/healthcheck-path: /
spec:
  rules:
    - host: app.anandcloud.com
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: fastapi-app
                port:
                  number: 80
```

## Usage

### Prerequisites
- Docker installed
- AWS CLI installed and configured
- `kubectl` installed
- Access to the EKS cluster
- Container registry permissions for Amazon ECR

### Build and push image

Example flow:

```bash
docker build -t fastapi-app .
docker tag fastapi-app:latest <account-id>.dkr.ecr.eu-west-2.amazonaws.com/fastapi-app:latest
docker push <account-id>.dkr.ecr.eu-west-2.amazonaws.com/fastapi-app:latest
```

### Deploy through GitOps

Push Kubernetes manifest changes to this repository and let Argo CD reconcile the desired state into the cluster.

Useful validation commands:

```bash
kubectl get pods -n fastapi-app
kubectl get svc -n fastapi-app
kubectl get ingress -n fastapi-app
kubectl describe ingress -n fastapi-app flaskapp
```
